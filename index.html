The plain version

No mystique, no methodology deck

I sit down with a model and work the problem in writing. Architecture arguments, schemas, payment flows, the copy on the buttons — most of what I've built came out of that.

State the problem in the operator's words. Load the real context — the constraint, the history, the exception everyone knows and nobody wrote down. Build the check before the thing. Correct in short cycles until it holds twice. I start at about seventy percent of what there is to know, because the last thirty usually isn't in anyone's head waiting to be asked for. It shows up faster by building.

Before this, twenty years on the operating side — two companies, property development, eight trades, footings I dug myself. Models are short on lived context and long on everything else. Mine is the scarce half.

How the loop runs

Four moves, in order

01Frame

State the job in the operator's words, not the system's. If I can't, I don't understand it yet and no amount of prompting fixes that.

02Load

Give the model the real material — actual records, actual constraints, the thing everyone already knows. Most implementations underperform because they were built against a description of the work instead of the work.

03Verify

Build the check first: ground truth, a test, or a person who'd notice. No verifier, no loop. This is where I spend the time.

04Correct

Run it again with what failed. Short cycles, visible each time, stop when it holds twice. Small increments beat one long unattended run, every time.

Where it's going

Better lives for all humans

The architects worth watching now are building off-world: closed-loop energy, food, water, air, shelter. Systems that have to work with no margin and no resupply.

Those constraints produce technology that fixes things here. A habitat that must generate its own power and grow its own food is the same engineering problem as a house that should.

The mission is the many, not the few. More privilege for a handful is an uninteresting outcome, and always was.
